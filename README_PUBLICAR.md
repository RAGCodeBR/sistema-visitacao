# Therapeutica Visitas - Versao Compartilhavel

Esta pasta e uma versao demo estatica do app.

Ela funciona sem backend e salva os dados no navegador de cada pessoa que testar usando `localStorage`.

## Como publicar no GitHub Pages pelo GitHub Desktop

1. Abra o GitHub Desktop.
2. Clique em `File` > `Add local repository`.
3. Selecione esta pasta:
   `C:\Users\User\Documents\Codex\2026-07-09\e\outputs\therapeutica-visitas\compartilhavel`
4. Se o GitHub Desktop pedir, clique em `create a repository`.
5. Publique o repositorio no GitHub.
6. No site do GitHub, abra o repositorio publicado.
7. Va em `Settings` > `Pages`.
8. Em `Build and deployment`, escolha:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
9. Salve.
10. O GitHub vai gerar um link publico para compartilhar.
